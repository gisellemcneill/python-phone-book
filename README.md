# Python Phone Book

This is a python program that runs inside the terminal that accepts user input 
to create a phone book log. 

## Features
- Add contacts to the phone book
- Remove contacts from the phone book
- Search up contacts within the phone book
- Display all contacts in the phone book

## Technologies Used
- Python

## What I Learned
- Learned how to apply core concepts such as loops, variables, methods to a new language
- Worked with dictionaries and created a nested dictionary
- Used case insensitive logic to disallow duplicates
- Utilized a matched_key pattern to prevent iterating while modifying errors

## Future Improvements
- Support multiple contacts with the same name by assigned each a unique ID

## How to Run
- Clone the repo
- Run python3 practice.py
